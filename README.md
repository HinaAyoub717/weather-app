# Weather App

A simple weather app built for my internship task. Enter a city name to see its temperature, humidity and weather conditions, with an icon for each.

Live demo: https://hinaayoub717.github.io/weather-app/

## Features
- Search the weather by city name
- Shows temperature, humidity and conditions
- Weather icon (sunny, rainy, cloudy and more)
- Error message for incorrect city names

## Built with
HTML, CSS, JavaScript (fetch API) and the Open-Meteo API

## What I learned
- Fetching data from an API using fetch()
- Handling JSON responses
- Updating the DOM dynamically

## How to run
Open `index.html` in your browser.
